PDF 도구

        
PDF 합치기 · 페이지 추출 · 회전

        
PDF 파일을 병합하거나 원하는 페이지만 남겨 새 PDF로 저장하세요. 여러 이미지를 PDF 한 개로 만들 수도 있습니다. 파일은 브라우저에서 처리합니다.

        

          
          
          
        

        
        
        
여러 PDF를 합칠 때는 파일 선택 순서대로 배치됩니다. 파일당 25MB, 합계 80MB까지 지원하며 암호화된 PDF는 처리할 수 없습니다.

        

        
PDF 기능은 실행할 때 pdf-lib 라이브러리를 불러옵니다. 인터넷 연결이 필요합니다.

기능

        
압축, 변환, 크기 조정

        
같은 옵션으로 여러 이미지를 한 번에 처리하고 결과는 파일별로 확인할 수 있습니다.

        

          

            압축
            
사진 용량 줄이기

            
JPEG·WebP 품질을 조절하거나 목표 용량을 지정하세요. 필요하면 용량을 맞추기 위해 이미지 크기를 낮출 수 있습니다.

          

          

            변환
            
JPG·PNG·WebP 형식 변환

            
JPG를 PNG로, WebP를 JPG로 저장할 수 있습니다. 브라우저가 지원하는 출력 형식만 선택 목록에 표시합니다. JPG로 바꾸면 투명한 부분은 흰색으로 채웁니다.

          

          

            크기
            
이미지 크기 변경

            
원본 대비 비율이나 출력 픽셀을 지정할 수 있습니다. 픽셀 지정 시 가로세로 비율을 유지할 수도 있습니다.

          

        

      


      

        
사용법

        
파일을 추가하고 옵션을 정하세요

        
JPG·PNG·WebP 파일을 추가하고 품질이나 목표 용량, 저장 형식, 크기를 정합니다. 처리 후에는 원본과 결과의 실제 용량을 비교한 뒤 파일별로 받거나 ZIP으로 묶어 저장하세요. 목표에 못 미치면 결과 크기와 이유를 표시합니다.

      


      

        
도움말

        
자주 묻는 질문

        

          

            파일이 서버로 업로드되나요?
            
아니요. 파일은 이 브라우저에서 처리하며 서버로 전송하지 않습니다. 목록을 비우거나 페이지를 닫으면 미리보기와 결과 URL도 해제됩니다.

          

          

            목표 용량을 항상 맞출 수 있나요?
            
목표 달성 여부는 실제 결과 파일 크기로 판정합니다. 맞추지 못하면 실제 용량과 ‘목표 미달’을 표시합니다. 자동 크기 축소를 켜면 해상도를 낮춰 다시 시도합니다.

          

          

            사진을 1MB 이하로 줄일 수 있나요?
            
목표 용량에 1,024KB를 입력하면 됩니다. 모든 이미지가 목표에 도달하는 것은 아니며, 자동 크기 축소를 켜면 해상도를 낮춰 다시 시도합니다.

          

          

            ZIP에는 어떤 결과가 들어가나요?
            
현재 설정으로 완료된 결과만 묶습니다. ZIP 자체에서 이미지를 다시 압축하지 않으며, 파일당 40MB·전체 50MB를 넘으면 개별 다운로드를 이용해 주세요.

          

          

            PNG의 품질 설정은 왜 적용되지 않나요?
            
PNG는 무손실 형식이라 품질 값을 적용할 수 없습니다. 용량을 줄이려면 크기를 낮추거나 JPG·WebP로 변환하세요.

          

          

            원본 메타데이터와 투명도는 보존되나요?
            
EXIF 등 원본 메타데이터는 보존되지 않습니다. PNG와 WebP의 투명도는 유지하고, JPG의 투명 영역은 흰색으로 채웁니다.

          

          

            애니메이션 PNG 또는 WebP도 처리할 수 있나요?
            
지원하지 않습니다. 애니메이션을 한 장의 이미지로 바꾸지 않도록 파일 추가 단계에서 안내합니다.

          

          

            완료 결과를 얼마나 보관하나요?
            
결과는 탭을 닫을 때까지 브라우저 메모리에 보관하며, 합계 128MB를 넘기지 않습니다. 한도를 넘는 결과는 파일별 오류로 표시됩니다. 다른 결과를 비우거나 출력 크기를 낮춰 다시 처리해 주세요.

          

          

            일부 큰 이미지가 처리되지 않을 수 있나요?
            
파일당 50MB, 입력 5천만 픽셀, 출력 한 변 16,000픽셀·총 2,400만 픽셀까지 처리합니다. 여러 파일은 한 장씩 처리합니다. 큰 이미지에서는 브라우저 응답이 잠시 늦어질 수 있으며, 메모리 부족이나 인코딩 오류가 생기면 해당 파일에 오류를 표시하고 다음 파일로 넘어갑니다.
