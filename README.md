# Filekit

이미지·PDF·텍스트·색상 작업을 브라우저에서 처리하는 웹 도구 모음입니다. 파일을 선택하고 작업 옵션을 정한 뒤 결과를 내려받는 흐름으로 구성했습니다.

## 주요 기능

- 도구 이름 검색과 카테고리 필터
- 이미지 압축, JPG·PNG·WebP 변환, 크기 조정과 이미지 효과
- 품질 또는 목표 용량을 지정하는 고급 이미지 처리 화면
- 이미지 일괄 처리, 작업 취소, 처리 전후 비교, 개별 및 ZIP 다운로드
- PDF 합치기·페이지 추출·회전
- 단색 배경 투명화와 이모지 검색·복사
- 텍스트 변환, 색상 계산 및 파일 분석
- 라이트·다크 모드와 모바일 화면 대응

## 실행 방법

1. 이 저장소의 **Code → Download ZIP**으로 소스를 내려받아 압축을 풉니다.
2. `index.html`을 최신 Chrome 또는 Edge에서 엽니다. JavaScript를 허용해야 합니다.
3. 별도 빌드나 패키지 설치는 필요하지 않습니다.

로컬 서버로 확인하려면 Python이 설치된 환경에서 다음 명령을 실행합니다.

```bash
git clone https://github.com/TonyU217/Filekit.git
cd Filekit
python -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 비공개 저장소는 GitHub 접근 권한이 필요합니다.

PDF 작업은 pdf-lib를 CDN에서 불러오므로 인터넷 연결이 필요합니다. SHA-256 및 클립보드 기능을 확인할 때는 HTTPS 또는 위의 localhost 환경을 사용하세요.

## 사용 흐름

도구 목록에서 필요한 작업을 검색하거나 카테고리를 고릅니다. 도구 화면에 파일 또는 텍스트를 입력하고 실행한 뒤 결과를 복사하거나 다운로드합니다. 여러 이미지를 한 번에 처리하려면 고급 이미지 작업 화면에서 옵션을 정하고 완료 파일을 개별 또는 ZIP으로 저장합니다.

## 기술 구성

HTML, CSS, JavaScript를 `index.html`에 함께 담은 정적 웹 프로젝트입니다. 별도 애플리케이션 서버나 빌드 도구 없이 브라우저에서 실행합니다.

이미지는 Canvas와 브라우저 파일 API로 처리합니다. 고급 이미지 화면의 ZIP 생성 로직은 소스에 포함되어 있으며, PDF 작업은 pdf-lib 1.17.1을 필요할 때 불러옵니다. 테마 설정은 `localStorage`에 저장합니다.

## 구현 포인트

파일 입력, 처리 진행 상태, 취소와 결과 다운로드를 브라우저 안에서 연결했습니다. 고급 이미지 작업은 파일 수·픽셀 수·결과 메모리 사용량에 제한을 두고, 사용이 끝난 Object URL을 해제합니다. 검색 메타데이터와 사이트맵 등 정적 사이트 운영 파일도 포함합니다.

## 참고 사항

파일 처리 로직은 브라우저에서 실행되며 선택한 파일을 처리 서버로 업로드하지 않습니다. PDF 라이브러리를 내려받는 외부 네트워크 요청은 발생합니다. 이미지 형식 지원은 브라우저에 따라 다르며, 애니메이션 이미지는 첫 프레임만 처리됩니다. 입력 크기 제한은 도구별로 다릅니다. 단색 배경 투명화는 인물·사물을 인식하는 AI 배경 제거 기능과 구별됩니다.

다른 주소로 배포할 경우 `index.html`의 canonical·OG·구조화 데이터·URL 설정과 `robots.txt`, `sitemap.xml`의 주소를 함께 확인하세요.
